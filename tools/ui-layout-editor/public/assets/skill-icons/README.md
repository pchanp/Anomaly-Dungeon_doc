# スキルアイコン 制作規格（暫定案）

**Status: Draft（すべて第一稿の仮案。ゲーム内実装アセットではない）**

このディレクトリのSVGは、`docs/systems/skill-build.md` に記録された個別スキル案に対する
**目視レビュー用の第一稿**です。ゲームアセットとして確定したものではなく、実装もしていません。
配合（スキル仕様・数値・効果量）は一切創作していません。アイコンには形状の suggestive な表現のみを含みます。

- 正本: [`docs/systems/skill-build.md`](../../../../docs/systems/skill-build.md)
- レビュー用レイアウト: [`../samples/skill-icon-review.yaml`](../samples/skill-icon-review.yaml)
- ファイル名は **意味が通る暫定アセット名**です。ゲームの安定System IDは未決定のため_seg.svg* のようにシステムIDを名乗っていません。表示名と実装IDは同一視しません。

## 共通規格

| 項目 | 値 |
| --- | --- |
| canvas | `viewBox="0 0 96 96"`、`width/height=96`、**背景は透明** |
| 枠 | 焼き込まない。既存の `assets/slot_normal.svg` / `assets/slot_selected.svg` と重ねる前提 |
| 主線幅 | 4〜9（重量差で主次的シルエットを示す） |
| 副線幅 | 3。破線（`stroke-dasharray`）は移動・範囲・不可視表現にのみ使う |
| 線端・線接合 | `round` 固定 |
| 余白 | 描画は 14〜82 の範囲に収める。96px 表示でも 48px 表示でも判読できる密度を保つ |
| 形 | 面ではなく線（stroke）で構成。塗り潰しは点のように小さな用途のみ |

### 色

黒・深緑を基調とした、メインフレーム制御盤/ワイヤーフレーム調。

| 役割 | 色 |
| --- | --- |
| 図案の地色（シルエット） | `#dfeae4` |
| アクセント（系統色） | 攻撃 `#f0603c` / 探索 `#e8b13a` / 補助 `#4fd6c0` / アクション `#7fb0ff` |
| 共通アクセント（効果・軌跡） | `#6fe3b0` |
| 奥義 | `#ff8a3c` + `#ffd166` のみ。線数を増やして密度で格上を示す |

背景色は指定せず透明のままです。黒・深緑の地色は実機UI側のフレームに任せます。

## 見分ける設計

- 系統は**色**で、効果は**小さな識別要素**（点線circle＝範囲、破線＝不可視/移動、直線＝方向）で表します。
- アイコン本体のシルエットが最優先で、系統色は従属する面積を小さく保ちます。
- 奥義「絶炎衝」だけは線数・色数ともに増やし、他の16種と密度で差をつけます。

## 避けているもの

- 元ネタ作品・実在人物の意匠の模倣
- サイバー／Windows 95風／ホラー記号の多用
- スロット枠の焼き込み、背景の塗り
