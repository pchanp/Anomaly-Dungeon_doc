# 設計判断記録

重要な設計判断と、その判断に至った理由をここに保存します。`001-anomaly-exposure.md` のように、原則として1つの判断につき1つの番号付きファイルを作成してください。

設計判断記録には通常、以下を記載します。

- 状態と日付
- 背景
- 決定内容
- 判断理由
- 影響
- 関連資料または関連する実装領域

判断が変更された場合は、以前の判断を置き換える新しい記録を追加してください。過去の判断理由を削除しないでください。
