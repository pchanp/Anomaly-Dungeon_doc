# 010: レアルート品によるSecure Slot成長

**Status: Accepted（採用）**
**Date: 2026-10-01**

## 背景

総インベントリ20枠、初期Secure Slot 4枠、失敗時はSecure Slot内の物だけを持ち帰れるという最小Runの境界はある。一方、Secure Slotをどう成長させるか、どこで行うか、通常の所持枠とどう関係するかは未決定だった。

レアルート品は、通常換金とは別の価値を持ち、特定NPCへ渡すことで成長や研究に使えるアイテム群として扱う。単なるCredits消費だけで安全資産を増やすのではなく、探索・観察・取引判断がSecure Slot成長へ接続する必要がある。

## 決定内容

### 研究室での強化

都市ロビーのアノマリー研究室で、ダンジョンを自ら作ったと主張する研究者NPCを通じて永続的なインベントリ強化を行う。研究室は、アノマリーを完全に鑑定する場所ではない。正体不明の価値を持つレアルート品を、探索者が危険な資産を確保するための変化へ使う場として扱う。

世界観上の意図的な曖昧さとして残すのは、研究者の「自分が作った」という主張の真偽、ならびにダンジョンの起源である。

### Secure Conversion

通常スロット1枠をSecure Slotへ変換する永続強化を設ける。

- レアルート品を消費する。
- 総インベントリ枠数は増えない。
- 失敗時の保持判定は、変換後のSecure Slotへ適用される。

### Capacity Expansion

総インベントリの枠数自体を増やす永続強化を設ける。

- Secure Conversionと同種のレアルート品を消費する。
- 追加枠の初期種別、交換レート、上限は今回確定しない。

## 課金経路の扱い

レアルート品をRobuxで変換・取得できる経路は **Idea（未採用）** とする。これはソーシャルゲームの「石」に相当する機能上の比較であり、現時点で直接購入、変換比率、販売形態、実装を決めるものではない。

採用判断は、レアルート品の通常入手量、Secure Slotの成長曲線、失敗時の喪失、協力プレイの経済、プレイヤー間の公平性を含むゲームバランス設計の後に行う。

## 影響

- ItemStackと取得源が実装されると、レアルート品を換金・Quest・研究室強化の間で選ばせられる。
- 研究室は、ロビーにおけるビルド／資産管理の施設候補になる。
- Secure Slotを増やすことはリスク軽減に直結するため、交換レート・上限を実装より先に決める必要がある。
- 課金経路を検討する場合も、通常プレイでのレアルート品の価値と入手を先に定義する。

## 未決事項

- レアルート品のItem ID、取得源、通常換金額、研究室以外での用途。
- Secure ConversionとCapacity Expansionの必要量、段階的な増加、上限。
- Capacity Expansionで追加した枠が通常／Secureのどちらとして始まるか。
- Secure Slotへの入出庫時点と、Player Anomaly時の利用制約。
- Robux変換・取得経路を採用するかどうか、および採用する場合の制約。
