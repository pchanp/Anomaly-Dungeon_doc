# 012: アノマリー相互作用による固有スキル取得

**Status: Accepted（採用）**
**Date: 2026-10-01**

## 背景

汎用スキルレアルート品とスロットレアルート品は、研究室で交換対象を選べる成長資源として扱う。一方、個別アノマリーの特徴をスキルへ接続するには、汎用資源だけでは「何と相互作用したのか」という探索上の意味が失われる。

また、博士のQuestを単なる報酬受け取りにすると、アノマリー相互作用を起こす意義が弱くなる。

## 決定内容

### 固有の交換品と専用スキル

個別アノマリーの一部または関連アイテムを、そのアノマリーの特徴を冠する専用スキルとの交換品として扱う。

- 固有品は汎用スキルレアルート品ではない。
- 固有品は対応する専用スキルにのみ使う。交換対象を任意に選べない。
- 専用スキルはアノマリー能力の完全コピーではなく、探索者が利用できる不完全な技術として扱う。
- 個別アノマリーを設計する際、相互作用、固有品、専用スキルを同時に記録する。

### 博士のQuest

博士のQuestは、通常の研究対象となるアノマリーを発見し、指定された相互作用を成立させる調査依頼である。依頼には撃退、沈静化、観察、NPCへのアノマリー的干渉を含め得る。

プレイヤーが実行すべき目的は明確にするが、博士が何を研究しているか、なぜその相互作用を求めるか、固有品の正体は説明し尽くさない。

固有品はQuestの報告時に直接渡さない。Quest中に目的の相互作用が成立した時点で、アノマリー側から出現する。

### 研究対象外のレアアノマリー

FILE、NPC、環境などから現れる、博士の研究対象外となるレアアノマリーも存在する。博士のQuestを受けていなくても、相互作用を成立させれば固有品と専用スキルを得られ得る。

### Party配分

固有品は、条件を成立させた同一Runのパーティ全員が獲得する。切断者・条件成立時に不在の参加者の扱いは、再接続とItemStackの仕様が決まるまで未決定とする。

## 影響

- Anomaly Interactionには、状態変化だけでなく固有品の出現とParty配分を表せるResultが必要になる。
- Questデータは、博士の調査対象と、報告の直接報酬ではない相互作用目標を区別する必要がある。
- 個別アノマリー資料には、博士のQuest対象か、研究対象外のレアアノマリーかを記録する必要がある。
- Mad Stomper（`GIANT`）では、左足を肥大化させる花の胞子を固有品として扱う。専用スキルの名称・効果は未決定である。

## 未決事項

- 固有品と専用スキルのシステムID、外見、効果、交換操作。
- 博士のQuestで使う具体的な依頼・NPC干渉の内容。
- 研究対象外のレアアノマリーの出現・発見方法。
- 固有品のParty配分における切断者・不在者の扱い。
- 専用スキルと汎用スキルのスロット競合、取得・強化・失効の詳細。
