# Mad Stomper

**Status: Draft（草案）**
**Type: Anomaly Entity**

## 識別子と名称

- **System ID:** `GIANT`
- **現在のプロトタイプ表示名:** `Giant Anomaly`
- **設計上の名称:** `Mad Stomper`

上記は同一のAnomaly Entityを指す。`GIANT`は実装上の安定IDとして維持する。最終的なプレイヤー向け表示名を`Mad Stomper`にするかは、外見・演出と合わせて未決定である。

## 実装状況

**Prototype: Partially Implemented（Studio確認: 2026-09-26）**

Studioには`GIANT`／`Giant Anomaly`として、Mad Stomperの巨人プロトタイプがある。ランダム移動、ストンプ、カメラシェイク、Anomaly Level増加、Heal Fieldによる鎮静、スキンメッシュ、歩行アニメーションを実装済み。最終表示名、外見、鎮静後の挙動は確定していない。

## 概要

Mad Stomperは、青緑色の異形の身体、多数の眼、巨大な足を持つ巨人型アノマリー。プレイヤーを単純に殺す敵ではなく、**通過を妨げる巨大な環境アノマリー**として設計する。

## 外見と移動

- 巨大な人型／巨人型。
- 青緑色の身体、多数の眼、巨大な足。
- 感染・異常生物を想起させる外見。

歩行時は片足を大きく持ち上げてから地面へストンピングし、地響き、足音、低周波的な衝撃音、周囲の環境反応を発生させる。画面揺れは視認性を損なうほど強くしない。

## 遭遇と解決

通常のHPを削って倒す敵にはしない。攻撃の目的は撃破ではなく、一時的に動きを止める、または鎮静化することである。特定のHeal系スキルによって鎮静化できる案とする。

```text
Mad Stomper出現
    -> 歩行・ストンピング
    -> 進路が妨害される
    -> 対応方法を判断する
    -> Heal系スキルで鎮静化
    -> 一時的に安全な状態になる
    -> 通過する
```

Healを単なるHP回復ではなく、アノマリーを正常化する能力として利用できるようにする。

### 固有スキルへの接続

**Status: Draft（専用スキルの詳細は未決定）**

左足を肥大化させている花の胞子を、沈静化の相互作用で得られる関連アイテムとする。この品は通常のQuest報酬ではなく、相互作用の成立で同一Runのパーティ全員へ出現する。

対応する専用スキルの名称、効果、最終的な外見は未決定である。花の胞子と専用スキルの取得経路は設計済みだが、実装済み仕様とは扱わない。

## ビルドとの相互作用

特定ビルドを必須にしない。Heal、Mobility、Combat、Explorationの各ビルドで異なる対応余地を持たせ、特にHealを積んだプレイヤーに通常戦闘とは異なる価値を作る。

## 設計原則

「巨大な敵だから倒す」という構造にしない。Mad Stomperは敵NPCではなく、動いている巨大な異常現象として扱う。

## プロトタイプ要件

- 仮モデル。
- ストンピング歩行と足踏みアニメーション。
- 地響き、画面揺れ、サウンド。
- 一定条件での鎮静化テスト。

最終リグと最終アニメーションは後工程で差し替える。
