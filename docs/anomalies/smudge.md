# smudge

**Status: Idea（アイデア・未採用）**
**Type: Anomaly Entity**
**記録日: 2026-10-06**
**Prototype: 未実装（今回Studio確認・実装は行っていない）**

## 名前と核

- **System ID候補:** `smudge`。小文字表記を維持する。正式な実装IDとしては未登録。
- **ゲーム内表示名:** 未定。

人格の抜け落ちた人型の転写。ある解釈だけが、異様な濃さで残っている。話しかけると、その偏りがプレイヤーの言葉とInteractionへ擦りつく。

単体で出現する案。特定マップへの固定、群体、点在する全個体との会話を前提にしない。出現マップ・確率・出現数の正式設定は未定。

## 外見の方向

人の姿を連想させる、空間に残った擦れた転写跡。顔に人格を感じさせず、内部の濃淡や欠落に偏りを持たせる。

- 身体と周囲の染みが連続し、主体の境界が曖昧。
- 薄い膜、半透明の面、拭き残し、ずれた転写の質感。
- 褪せた灰白・青紫・桃色。威嚇する発光より、静かな不協和を重視する。
- 人体の生々しい変形や、黒い液体の怪物へ寄せすぎない。

この世ならざる残滓、溶け出す言語的思念を連想させるが、死者・思念であるとは断定しない。没人格的な姿に、過剰に偏った言葉の使い方が伴う。

ビジュアル方向の参考は、相談時に提示されたLeonardo AI生成画像（ファイル名 `lucid-origin_Faded_transfer_marks_left_in_the_space_evoking_the_image_of_a_human_figure._Lack-1.jpg`）。最終アセットではなく、画像そのものは今回のコミットに含めない。

## 話しかけると、Interactionが侵食される

会話をきっかけに、プレイヤーのInteraction文言やUIの言葉が置換される。自然な言い換えから、読めそうで読めない語形、意味の偏った文章へ変質する。表示だけでなく、通常のInteractionが正常に成立しなくなる場合がある。

例として「渡す」が「返す」、「話しかける」が「照合する」になるなど。これらは方向の例示であり、正式な置換表ではない。強い崩れ方を含め、具体的な文言・侵食範囲・進行条件は未定。

効果は対象プレイヤーの**同一Run中**に継続し、マップ遷移でも原則保持する。Run終了で破棄する。途中解除手段は未定であり、音楽干渉がプレイヤーの侵食を解除するとは決めない。

```text
初見で話しかける
  → 言葉・Interactionが変質する
  → 経験後は接触を避ける
  → 変質状態の用途を知り、再び関わる理由が生まれる
```

変質状態は、あるゲームギミックや別のAnomaly Entityへの干渉条件に接続する。特定の置換状態で特定のInteractionを行うと、通常は起きない反応が成立する案。接続対象・条件・結果は未定。

全ての置換に用途を付ける必要はない。専用文章を解読して完結する謎や、全個体との会話で完全解読する構成は現在の前提から外す。

## smudge自身への干渉：音楽に侵食される

プレイヤーが侵食される接触とは別に、smudgeへ音楽を聞かせる案。

| 経路の候補 | 行為 |
| --- | --- |
| 携帯再生 | ある場所のQuest報酬で音楽プレイヤーを入手し、廃TSUTAYAで入手する特定のCDを再生する |
| 店内放送 | 廃TSUTAYAのバックルームで、そのCDを店内放送する |

二経路を代替にするか、両方を成立させるかは未定。携帯再生経路はsmudgeを廃TSUTAYAに固定しないための接続にもなり得るが、使用可能マップは確定しない。Questの場所・依頼主・目的、プレイヤーとCDの名称、取得条件、放送設備の実装は未定。

音楽を聞いたsmudgeは、旋律や歌詞を反復し始める。普段は他者の言葉を侵食する存在が、今度は音楽によって侵食されていく。

それが鎮静、回復、悪化、別の偏りへの変化のどれなのかは説明しない。**音楽干渉が成立したことは観察できるが、良い方向に向かったかは分からない。** 具体的な動き・声・視覚変化、必要な再生時間、反復後の挙動は未定。

音楽の反復は意図する挙動であり、実際の音声・歌詞解析を必須にしない。ゲーム内の曲IDとサーバーが確認できる再生状態をSound Interactionへ渡す実装が候補。架空楽曲を想定し、既存曲・歌詞をそのまま流用する仕様にはしない。

## 専用スキルへの接続

音楽による干渉から、アノマリー干渉スキルの獲得へつなげる案。名称・効果・ランク・装備枠の扱いは未定。他アノマリー全般へ通用する万能能力とは決めない。

既存の採用済み取得経路に沿わせる候補は次のとおり。

```text
Quest報酬の音楽プレイヤー ＋ 廃TSUTAYAの特定CD
  → smudgeへの音楽干渉が成立
  → smudge固有の一部／関連アイテムが出現（内容未定）
  → 対応する博士Questを受注中に研究室で交換
  → 専用スキルを獲得
```

音楽プレイヤーは通常Questの報酬候補、CDは探索で入手する媒体候補、smudge固有品はAnomaly Interactionの結果として得る交換品候補であり、互いに混同しない。

直接スキルを付与する方式も相談の意図には含み得るが、判断012・014とは異なるため、採用時に別途判断する。今回は直接付与へ仕様変更しない。

博士の通常研究対象か研究対象外のレアアノマリーかは未定。既存規則では固有品の取得にQuest受注は不要、専用スキルへの交換には対応博士Questの受注が必要。同一RunのParty全員への固有品配分を基本とし、不在・切断者は既存の未決事項を維持する。

## 効果と相互作用の境界

| 項目 | 現時点の案 |
| --- | --- |
| 接触のTrigger / Condition | smudgeに話しかけ、会話が成立する。距離・会話の成立点は未定 |
| 対象・作用範囲 | 接触したプレイヤー個人。Party全員へ自動波及しない |
| Effect | 表示・認識の変質は`InformationChange`。Interactionの変換・不成立は対象を限定した`RuleOverride`候補 |
| 保存・終了 | 同一Run中。Run終了で破棄。途中解除、死亡・切断・再接続の扱いは未定 |
| 重ね掛け | 同じEffectの加算は既定で行わない。再接触による進行・累積は未定であり、無制限増殖は確定しない |
| Feedback | 文言・文章とInteraction結果の変化。影響対象や失敗理由を判断できる表現は要検討 |
| 音楽の入力 | `Sound`。Itemの使用、または放送設備の操作が起点 |
| 音楽のCondition | 特定曲がsmudgeへ届くこと。範囲・遮蔽・時間・音源競合は未定 |
| 音楽の結果 | smudgeの反復と侵食は`StateChange`候補。作用範囲・保存境界・終了・重ね掛けは未定 |
| Server / Client | Serverが侵食状態、許可するInteraction、音楽干渉と報酬を確定。Clientは個人の表示・音響を提示する候補 |

表示された文字列自体を判定キーにせず、内部のInteraction種別と置換状態を分ける。個人のUI侵食と、店内放送のServer共有状態は別に保持する。音量設定だけで成立条件が変わるかは未決定。

**requires_code: true（実装する場合）**。置換状態、UIへの適用、通常Interactionの変換、音源からの受理、反復と固有品の成立処理が必要。夜間自動実装や採用を許可する指定ではない。

## 未決定・採用時の論点

- 出現候補マップと単体出現の具体的な制限。通常NPCやモブとして扱わない。
- 置換対象、通常操作が壊れる範囲、侵食の進行と再接触、回避・解除手段。
- 帰還や重要操作まで変質するか。「ルールは明確、意味は曖昧」と、誤操作・詰まりの境界。
- 変質状態が鍵になる対象。専用のマップ解読ギミックを前提に戻さない。
- 音楽プレイヤーQuest、CD、バックルーム放送の経路と、実際のStudio設備との差分。
- 音楽干渉後のsmudgeの状態と持続、報酬成立点、再取得・競合・Party配分。
- 固有品・専用スキル・対応博士Quest、ExposureとPlayer Anomalyとの関係。

言葉が認知・判断に干渉する着想として、オースティンの言語行為論、距離と他者への判断の関係が相談中に挙がった。学説の正確な要約や因果の裏付けは今回確認しておらず、デザインの着想としてのみ記録する。
