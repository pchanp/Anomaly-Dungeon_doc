# /dev/null

**Status: Draft（草案）**
**Type: Anomaly Entity**

## 概要

`/dev/null`は、入力されたものを「存在しなかったこと」にするアノマリー。ゴミ箱や廃棄物を象徴するオブジェクトではなく、**入力・命令・結果の対応関係をnull化すること**が本質である。

## 外見と挙動

外見は本質ではない。近傍ではプレイヤーの操作やゲームシステムの一部が正常に結果へ到達しなくなる。UI上でも名前や画像が正常に認識できない、または欠損する表現を検討する。

`/dev/null`は移動も攻撃もしない。一定範囲内のプレイヤーについて、通常攻撃、スキル、ダッシュ、ジャンプ、アイテム使用、インベントリ操作などの入力結果をnull化し得る。

```text
攻撃入力 -> 攻撃が発生しない
スキル入力 -> スキルが発生しない
アイテム使用 -> 使用結果が発生しない
```

これは単純なスタンではない。入力したにもかかわらず、その入力に対応する結果が存在しない感覚を作る。

## 警告と特殊な可能性

通常の敵より強い警告を行い、近づくと何かがおかしくなることを事前に察知できるようにする。ただし、すべての結果を明示的に説明しない。

捨てられないアイテムや通常では操作できない異常スロットまでnull化できる可能性を示唆する。これは通常のアイテム削除ではなく、対象に対する入力と結果の対応が失われる扱いである。

## ゲームプレイ上の役割

戦闘型ではなく、通常戦闘、スキル依存、アイテム依存、移動、探索など、プレイヤーが当然と考えるゲームシステムそのものを揺さぶる。

## 設計原則

「何でも消す能力」にはしない。ゲームの基本的な**入力 -> 処理 -> 結果**という因果関係を壊すことを中心に置く。
