# MiW

**Status: Draft（草案）**
**Type: Anomaly Entity**

## 実装状況

**Prototype: Implemented（Studio確認: 2026-09-26）**

棺、開封、棺の消去、座りモデルの出現、死亡抽選、毒ガス、ダメージ、行動制限、個人向けRun情報HUDまでデバッグフロアで実装済み。確率値、表示情報、保存・収集要素は確定仕様ではない。

## 概要

MiWは猫型のアノマリー。古代エジプト的な猫・バステト信仰と、シュレディンガーの猫のような「存在している／していない」という曖昧さをモチーフとする。

単純な敵ではなく、発見、観察、接触そのものにリスクがある存在として扱う。

## 外見

- 猫の姿をしている。
- 古代エジプトを想起させる意匠を持つ。
- 棺に収まっている状態で発見される。
- 詳細な外見は設定画像を基準とするが、ゲーム内では過度に説明しない。

## 挙動と危険

MiWは通常、棺の中に存在する。プレイヤーが棺を開けることでイベントが発生し、一定確率で死亡し得る。

この危険はMiW自身の直接攻撃というより、MiWを収めている設備全体に伴うものとして表現する。候補には、放射性物質を発生させる装置、毒ガス、開封時の大ダメージ、一時的な行動制限がある。

MiWを発見したこと自体が、即座に戦闘を意味するわけではない。

## Run情報

MiWは現在のRunに関係する存在可能性や内部変数を、一時的に表示する性質を持つ案とする。プロトタイプでは、プレイヤー個人に対して一定時間HUDを表示する形式を検討する。

この情報表示がMiWの本質的な能力なのか、プレイヤーがMiWを認識したことによる副作用なのかは確定させない。

## ゲームプレイ上の役割

- 探索対象
- リスク付きインタラクション
- 情報を与える存在
- ロア上のマスコット候補
- 収集対象候補

危険なアノマリーでありながら、保存・収集によってマスコット的な存在になる可能性を残す。

## 設計原則

MiWが何者なのかを完全に説明しない。古代エジプト、猫、棺、放射線、毒ガス、存在可能性の要素を個別に提示し、プレイヤー自身に関係性を考えさせる。
