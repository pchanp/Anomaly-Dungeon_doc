# W03-01：岩材質の通常Import検証準備

**Status: Draft（実行前の作業指示）**

## 目的・入力

既存岩試作を通常のFBX Importで取り込み、EditableMeshでのEdit配置とは別に検証する。制作・編集はCodex専用。統括担当は次回割り当てる。

- 正本：[材質試作とStudio記録](../../../references/material-preview.md)、[Roblox導入](../../roblox-import.md)、[判断024](../../../decisions/024-editable-august-map-authoring.md)。
- 入力：`work/material-preview/rock-v1/` のblend、`export/`のFBX、textures、sources.json、settings.json。試行開始時に存在・SHA256・出典・依存を固定する。
- 現在のStudio状態：記録上はプレース `99417611378273` の `Workspace.RockMaterialPreview` にEditableMesh試作あり。今回実構造を再確認していない。
- 依存：検証先・保存方法・実行範囲の人間判断、Studio接続、通常Importerへのアクセス。W01の完了待ちは不要。

## 範囲・上限

- 最初の実行は現物照合と入力固定。ツール操作は上記参照資料を読む。
- 制作記録と新規出力は `work/environment-assets/tasks/W03-01/runs/<run-id>/` を開始時に作成する。元試作と固定出力ツールを無条件に再実行しない。
- 上限案：既存2素材・同一岩形状、通常Importの1試行。新規生成・有料素材・ゲーム公開・本番マップ配置は対象外。
- 既存試作の置換／削除は行わず、検証用コピーの名称・置き場所・保存を先に決める。接続失敗、既存物との競合、結果不明なら停止して記録する。
- 未決：検証用プレースまたはコピーの選択、保存・再読込の方法、実行時間上限、対象端末・負荷計測条件。未決のままReadyへ進めない。

## 成果物・受け入れ

| 成果物 | 条件・証拠 | 受け入れ担当 |
| --- | --- | --- |
| 固定入力一覧 | 形状・材質・FBXの版と取得可能性を記録 | 統括担当 |
| 通常Import結果・RESULT | Import方式、Mesh、UV、Scale、法線、材質、依存Assetを記録 | Codexが技術検証、統括担当が確認 |
| 対象環境の証拠 | 見た目、衝突、Play、保存・再読込を個別Pass／Fail／Unconfirmedで記録 | Studio検証担当 |
| 美術レビュー | 2素材の比較と既知問題を人間が確認。正式採用と分ける | 人間 |

失敗・未確認を記録しただけで導入成功とはしない。通常Import成立と保存・再読込を確認するまで完了扱いにしない。結果は参照資料へ反映し、Workboardを更新する。受け渡しは [共通契約](../shared/handoff.md) に従う。
