## 4層のBrief

| 層 | 内容・根拠 |
| --- | --- |
| ゲーム機能 | 正本仕様のプレイヤー動作・用途。Draftと確定事項を区別 |
| 視覚的メタファー | 動作を見せる暫定表現。キャラクター・ロアの新仕様にしない |
| 視覚原則 | 形状、色、コントラスト、質感、情報密度。参考作品の持ち込まない要素を列挙 |

参考作品の固有衣装・装備・HUD・背景を、抽出した視覚原則と混同しない。参照画像を直接使用する場合は混入を別項目で評価する。プロンプト改善とゲーム機能の採否を分ける。
