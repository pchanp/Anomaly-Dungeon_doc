# 世界設定ドキュメント

世界観、ロア、用語、組織、ダンジョンの性質、意図的な謎をここに保存します。

必要に応じて、以下を区別してください。

- 作者側で確定している情報
- プレイヤーがゲーム内で知り得る情報
- 意図的に未解決または曖昧な情報

資料を完成させるためだけに、未知の起源や解釈を確定設定にしないでください。

## 現在の資料

- [舞台設定](setting.md) - 架空都市、平成的な既視感、技術文明の設計方針。
- [アノマリー世界観](anomaly-worldview.md) - アノマリーの定義、社会との関係、ダンジョンに関する意図的な未解決事項。
- [世界観の情報提示方針](information-design.md) - 明確にするゲーム情報と、断片として見せる世界情報の境界。
