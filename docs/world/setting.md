# 舞台設定

**Status: Draft（草案）**

この文書は、Anomaly Dungeon の舞台となる社会・都市・技術文明の基礎的な設計方針を定義する。アノマリーの定義は[アノマリー世界観](anomaly-worldview.md)、プレイヤーへの見せ方は[世界観の情報提示方針](information-design.md)を参照する。

## 基本コンセプト

舞台は、近未来的でありながら平成的な都市文化の記憶を感じさせる、現実世界のどの国・都市にも直接対応しない架空世界とする。日本を舞台として明示しない。

建築、UI、都市文化、平成期のアニメ・ゲームなどから想起される記号は用いてよい。ただし、現実の日本の地理、行政制度、歴史をそのまま再現しない。雰囲気は平成レトロ、近未来、都市伝奇、廃墟・旧施設、古い技術と新しい技術の混在を重ねる。

「既視感のある異世界都市」「都市文化と異常現象の同居」「未来なのに古い文明・設備が残る感覚」を参照方向とする。一方、特定の既存作品の設定、固有名詞、世界設定を模倣しない。

## 「日本ではない」ための原則

- 日本語だけで完結する現実的な街並みにはしない。看板や施設名には英語、架空言語、抽象的名称などを混ぜる。
- 実在する日本の都市、県、行政制度を直接使わない。
- 職業紹介、行政窓口、商業施設などの機能は存在してよいが、現実の制度そのものとして再現しない。
- 建築、UI、服装、商品、公共設備から平成的な既視感を作る。
- 国名、歴史、地理は、ゲームに必要になるまで過度に確定しない。

目標は「日本のように見える」ことではなく、「どこかで見たことがあるのに、どこにも存在しない」ことにある。

## 技術文明

高度な技術と古い技術が混在し、技術の更新は一直線ではない文明として扱う。たとえば高性能AI端末の横にCRT端末があり、高度な電子錠に物理鍵穴が残り、高性能な機械から紙の記録が出力される。最新設備であっても、UIには1990年代から2000年代を思わせる意匠が残り得る。

これは完全なレトロフューチャーの世界を定義するものではない。古い施設が現役で使われ、技術・運用・生活習慣の更新速度が揃っていないことを、都市の通常性として扱う。

## 未決事項

- 世界の国名、都市名、政治制度、歴史の詳細。
- 各施設の運営主体と、アノマリーに関わる行政・企業・研究組織の具体的な関係。

これらは舞台設定を完成させる目的だけでは確定しない。
