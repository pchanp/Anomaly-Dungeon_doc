# ロビー／ワールドマップ

**Status: Draft（草案）**

この文書は、ゲーム開始後の都市入口、2Dワールドマップ、施設内3Dへの移動を定義する。現在実装済みのサーバー生成ロビーとは別の将来設計であり、実装状況は[現在の実装状況](current-implementation.md)を正とする。

## 役割

ロビーは一般的な待合室ではなく、探索者が生活する架空都市への入口とする。同時に、Robloxゲームとしてすぐ遊び始められる即時性を維持し、長い導入や説明を必須にしない。

ロビーはクエスト受注、アイテム売買、装備変更、スキル・ビルド管理、NPCとの会話、世界観情報の収集、噂・イベント、ラン開始、生活拠点を兼ねる。

## 2Dワールドマップ

ゲーム開始時の基本ロビーは、AVG的な2Dイラストのワールドマップとする。プレイヤーは施設を選択し、マップは機能メニューではなく都市を眺める場所として扱う。

```text
                CITY DISTRICT
       [Employment Office]
 [Market]       [Archive]
       [Residence]
              [Dungeon]
```

2D表現は、都市の全貌を物理的に再現するための縮尺ではない。通常の都市生活とダンジョンの異常性の間にある、選択・観察の層として機能する。

## 施設内3D

施設を選択すると、小規模な3Dマップへ遷移する。候補には Employment Office、Market / Recycle Shop、Archive、Research Facility、Residence、Restaurant、Equipment Shop がある。

施設内では歩行とNPC会話によって機能を利用する。ただし巨大な探索マップにはせず、「メニューから機能を選ぶ」のではなく「世界の中に入り、その機能を利用する」感覚を目的とする。施設の数、接続、各施設の採否は未決定である。

## 導線と層の意味

Robloxの短い導線を否定せず、「遊園地の入口から架空都市そのものに入る」構造へ置き換える。

```text
2D WORLD MAP
    -> 施設内3D
    -> NPC / SHOP / QUEST / 出発準備
    -> ANOMALY DUNGEON
```

2D街、施設、ダンジョンの順に、通常の社会から局所的な生活空間を経て異常な探索空間へ移る。これはダンジョンの由来を説明するものではなく、プレイヤーが通常性から異常性へ移行するための表現上・導線上の設計である。

## 避けること

- 中世ファンタジーの冒険者ギルド、酒場、王国の討伐依頼を基本モデルにしない。
- 世界設定を読むことをラン開始の条件にしない。
- 2Dマップを単なる待機画面、施設内3Dを巨大な探索コンテンツにしない。
