# マップ案「戦場」

**Status: Idea（アイデア・未採用）**  
**記録日: 2026-10-04**

ユーザーが提案した新しいマップ案。「戦場」は現時点の呼称であり、正式なSystem IDは未設定。イベントステージとも呼べる特殊な探索空間として検討する。実装済み仕様ではなく、現行の最小Runの対象を変更しない。

## コンセプト：完全な異常空間における認知の反転

「戦場で正常なことはありません。起こること全てがアノマリーたり得ます。」

危険が常態となった戦場では、帰宅を願う声、過去の記憶、将来の生活についての会話など、日常的な出来事そのものがアノマリーに思えてしまう。完全な異常空間で、何を正常と感じるかが反転することをテーマとする。

異化するのは、家族の呼びかけや翌日の約束が持つ日常性と、危険に対する慣れ。アノマリーを「想定するモデルからの逸脱」と捉える[世界観](../world/anomaly-worldview.md)に接続する。戦場がどう生まれたか、声や記憶の正体、兵士が何者かを世界の真相として確定しない。

実在する戦争、国家、部隊、戦場、既存作品の再現は設定しない。既存案SEKIGAHARAとは別の候補として扱う。

## 構成と前後のループ

限りなく続く塹壕地帯を走る構成。進行方向を「前」、戻る方向を「後」とする。

- 初期位置から前方へ、塹壕3つ分の広さの空間を越えると、再生成された戦場マップの定位置へ戻る。
- 各ループ区間には、後方へ10塹壕分のマップがある。
- 後方の終端はループしない。後退を続ければ終端へ到達できる。
- 後方終端には、**Return PortalとTransition Portalの両方が最初から存在する**。
- ポータルの出現・有効化にギミック条件はない。

```text
後方終端                     初期位置／再配置先           前方の境界
Return + Transition ← 後方10塹壕分 ← ● → 前方3塹壕分を越える
                                              ↓
                                再生成された区間の定位置へ
```

この図は前後と接続の関係だけを示す。塹壕の正式寸法、形状、分岐、再配置の正確な座標は未設定。前方の反復は戦場内のループであり、後方終端のTransition Portalによる別マップへの遷移とは区別する。

## 危険と戦闘

- 敵モブと敵兵士は存在しない。
- プレイヤーは射撃・自爆ドローンを回避、撃墜しながら進む。
- 戦闘・回避の難易度はそこまで高くない方向を目指す。数値や出現頻度は未定。
- 直接的な死を想起させるゴア表現は用いない。
- ドローンを通常モブやAnomaly Entityとして扱うことは今回決めない。攻撃・回避対象としての分類、HPや撃墜判定は未確定。

### PvPのマップ固有例外

このマップではPvPのダメージ下限を適用せず、通常プレイヤー同士でも常にキル可能とする案。上限のない攻撃力を意味するものではなく、通常のPvP安全下限を外すという意味で記録する。

**この例外はゲーム内で一切説明しない**という提案を保持する。これは[判断019](../decisions/019-player-anomaly-runtime-pvp-and-return.md)の「通常プレイヤー同士には常にHP 80%下限を適用する」と明確に衝突する。019を変更した扱いにはせず、採用時に別の判断が必要な例外候補とする。

## アノマリーの発生

このマップの**アノマリー同時発生数は0**とする案。

空間、声、会話、記憶がアノマリーたり得るというテーマ上の意味と、ゲーム上の発生枠は区別する。Anomaly Entityの通常発生を0にする設定としての適用範囲と、Player Anomaly・Exposureへの扱いは未確定。Player Anomalyも同時発生数0だと自動的に解釈しない。

[判断017](../decisions/017-run-anomaly-spawn-components.md)はアノマリーごとの同種同時出現数とRun単位の変動を定めている。今回のマップ全体の0設定をどの階層で適用するか、出現数を変えるアイテムなどが0設定を上書きできるかは未決定。

## 日常が異常に感じられる演出

以下は提案された演出例であり、発生順序・頻度・共有範囲は未設定。

- 塹壕に隠れている間、母親や子供が「帰ってきて」と呼ぶ声が聞こえる。
- フラッシュバックとして、過去を想起させるイメージが見える。
- 自軍の兵士から「明日別れた妻に会いに行くが、やり直せると思うか？」と話しかけられる。

兵士の話題は本人の生活と目的に属し、世界設定やこの空間の仕組みを説明するための台詞にはしない。声の主が実際の家族か、イメージがプレイヤー本人の過去かは確定しない。

**前へ進むより、戻る場合の方が認知的な負荷のある演出が増える。** 射撃やドローンに対処する間とは異なる重さを、帰還へ向かう過程に置く。認知的負荷をExposure増加や操作阻害と同一視せず、そのゲーム効果の有無は未決定とする。

## プレイヤーの選択と報酬

- **前進を続ける**：反復する戦場を進み、レアルート品が出現する可能性を追う。
- **後退して戻る**：日常を想起させる演出を受けながら後方終端へ到達する。
- **終端で帰還する**：Return Portalを選び、現在のRunから帰還する。
- **終端で探索を続ける**：Transition Portalを選び、次のマップへ向かう。

前進によるレアルート品の種類、出現条件、確率、ループごとの再抽選や配分は未定。[判断011](../decisions/011-real-route-acquisition.md)の既存取得経路に対する追加候補として扱い、アノマリー固有交換品との対応を創作しない。

## 既存仕様との関係と未確定事項

| 論点 | 今回の案と残る判断 |
| --- | --- |
| 通常PvPの安全下限 | 019の採用済み共通ルールに対するマップ固有例外。適用・解除境界やマップ外への影響を採用時に定義する必要がある |
| ルールの非説明 | PvP例外を一切説明しない案は「ルールは明確、意味は曖昧」と衝突する。説明しない提案を勝手に通知案へ置き換えず、学習可能性・判断可能性をレビューする |
| 初期状態から使える両ポータル | Gimmick成立で有効化する通常案に対する例外。出現・有効化条件なしという今回の案と、Portal通過後の処理を分ける |
| TransitionのParty条件 | 過半数・30秒カウントダウン等の既存案を、このマップでも使うかは未決定。「出現条件なし」が通過条件の撤廃を意味するとは決めない |
| Player Anomaly | 入場・変化・Exposure・兵士とのInteraction・後方Returnの利用可否は未決定。019の通常Return利用不可を黙って解除しない |
| マルチプレイのループ | 前進者と後退者が分かれた際の再生成、区間共有、NPC・ドローン・アイテムの保持と破棄、PvP対象の位置関係は未決定 |
| 反復と報酬 | ループ回数の保持、レアルート品の無制限再抽選の可否、取得済み状態は未決定 |
| 終了条件 | ポータル以外の時間制限、Run Termination、死亡・切断、Questや持ち帰りの成功判定は未設定 |

### 現行の実装範囲

[判断005](../decisions/005-minimum-lobby-run-scope.md)の最小RunはTSUTAYAとAUGUST_31の2種から1マップを選び、マップ間遷移を含まない。この「戦場」案は将来候補として残し、最小Runの抽選対象や実装範囲には追加しない。進行中のOpenCode 3担当の試走にも追加しない。
