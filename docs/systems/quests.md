# クエスト

**Status: Draft（草案）**

この文書は、ランの目的としての Quest の情報設計と世界内での扱いを定義する。Quest と FILE、Achievement、Discovery の分離は既存の[ゲームループとポータル遷移](game-loop.md)に従い、現在の実装範囲は[現在の実装状況](current-implementation.md)を参照する。

## 基本思想

クエストの目的は明確にする。「世界の謎を解け」ではなく、生活的で具体的な依頼を基本にする。例として、治療に必要な薬草や医薬品材料の回収、旧施設からの部品回収、行方不明者の所持品探索、指定物品の持ち帰り、指定地点の調査、写真撮影、特定の異常現象の確認がある。

基本構造は以下とする。

| 要素 | 方針 |
| --- | --- |
| 目的 | 明確 |
| 手段 | 危険 |
| 対象 | 異常であり得る |
| 依頼主の事情 | 部分的に理解可能 |
| アノマリーの意味 | 不明 |

Questは、ダンジョン入口ロビーからのマップ抽選に関与しない。目的地を制御する条件ではなく、抽選されたマップ内でプレイヤーが達成を目指す目的として扱う。最小Run終了時には、獲得物と保有Questごとの達成状況をリザルト画面に表示する方針である。詳細は[005: 都市ロビーから開始する最小Runの範囲](../decisions/005-minimum-lobby-run-scope.md)を参照する。

## 保有枠とDiscoveryの分離

同時に受注できるQuestは合計4件とする。

| 区分 | 上限 | 役割 |
| --- | ---: | --- |
| 博士のQuest | 1件 | アノマリーの調査と相互作用。受注中は対応アノマリーの個別出現確率を上げる |
| その他のQuest | 3件 | 市民、施設、業者などからの生活的・具体的な依頼 |
| 合計 | 4件 | 同時に受注できるQuest全体の上限 |

博士Questの受注は、マップ抽選の候補・確率を変えない。マップが選ばれた後、そのRun内で対応アノマリーの**個別出現確率**だけを基礎値の1.40倍へ上げる。これは候補全体の割合やマップ抽選重みを変えるものではない。

同一マップ内でアノマリーが1体発生するごとに、すべてのアノマリー候補の個別出現確率は0.90倍になる。発生済み数を`n`としたとき、基礎確率へ掛ける減衰は`0.90^n`とする。博士Quest対象は、これに加えて1.40倍を適用する。同種アノマリーは、一部の例外を除き同一マップに1体だけ発生する。

博士Questは各プレイヤーが1件まで受注できる。Run開始時にサーバーは、開始時Partyの博士Questから対応アノマリーIDの重複を除いた集合を作り、Runの初期状態として保持する。異なる博士Questの対象はそれぞれ個別出現確率を1.40倍へ上げる。同じ対象のQuestを複数人が受注しても、1.40倍が重複して掛かることはない。対象が選択マップの出現候補に存在しない場合、この補正は他候補へ移らず、そのRunでは何も起こらない。

この集合はRun中に再計算しない。途中でプレイヤーが脱落・切断しても、対応アノマリーの出現確率は下がらない。複数人が異なる博士Questを持って開始したRunは、途中でソロになっても複数の対象が強化された出現状態を維持する。そのため、マルチ開始からソロへ移行したRunは、ソロ開始時よりアノマリー遭遇率が高くなり得る。

**Discovery**は、FILE、NPC、環境、アノマリー、関連アイテムなどを発見・認識したという記録であり、能動的な依頼ではない。Quest枠を消費せず、Questの達成・失敗・報酬とは別に扱う。Discoveryの保存期間、UI、Quest解放との正確な関係は未決定である。

## 依頼主と感情表現

依頼主は世界設定を説明するNPCではない。たとえば家族の治療を必要とする人物は「娘の治療に必要なんです」まで伝え得るが、なぜその薬草が必要か、なぜダンジョンにしかないのか、安全かどうかまで説明する必要はない。

依頼主は必要事項を話し、受け取り後に短く礼と報酬を示す演出を基本候補とする。深い事情を語らないことによって、プレイヤーが背景を補完できる余地を残す。

## 対象物の不明さ

目的物は用途不明、異常な形状、生物的、明らかに危険、普通の物品に見えるが挙動がおかしい、といった性質を持ち得る。重要なのは、依頼の目的が分かる一方で、依頼物の意味や世界的な位置付けが分からないギャップである。

目的の不明瞭さを常態化させない。謎にするのは「それが何か」「なぜ必要か」「何が起きているか」であり、プレイヤーが何をすべきかではない。

## 成長資源との接続

低難度以外のQuestは、Creditsや通常の報酬に加え、汎用スキルレアルート品またはスロットレアルート品を報酬に含め得る。後者は相対的に希少とする。具体的な難度区分、報酬量、各依頼との対応は未決定である。

チュートリアルQuestを採用する場合は、レアルート品を報酬にして、都市ロビーのアノマリー研究室で汎用スキルまたはスロット強化へ交換できるという**ゲーム上のルール**を明確に伝える。アノマリーの正体や研究者の主張を説明する用途にはしない。

### 博士の調査Quest

博士のQuestは、通常の研究対象となるアノマリーを発見し、指定された相互作用を成立させる依頼である。撃退、沈静化、観察、NPCへのアノマリー的干渉など、内容は怪しげでも、プレイヤーが実行すべき操作目標は明確にする。

このQuestでアノマリー固有の交換品を直接報酬として渡さない。Quest中に目的の相互作用が成立した時点で、対応するアノマリーの一部または関連アイテムを出現させる。固有品は、アノマリーの特徴を冠する専用スキルとの交換にのみ使う。

対応する博士Questを**受注中**であれば、固有品を先に取得していた場合でも研究室で専用スキルへ交換できる。Questの完了・報告は交換の前提にしない。したがって、Quest外で偶然得た固有品も、対応する博士Questが解放された後に受注すれば即座にスキル化できる。

博士の研究対象外となるレアアノマリーも、FILE、NPC、環境などを通じて発見できる。この場合も、相互作用が成立すれば固有品を得られ得る。専用スキルへの交換には、対応する博士Questの受注が必要である。研究対象外のレアアノマリーに対応する博士Questをどう解放するかは未決定である。
