# 経済と成長

**Status: Draft（草案）**

この文書は、アノマリーに関わる換金、価値の違い、ビルド／スキル強化を世界内でどう解釈するかを定義する。数値、インベントリ、Secure Slot、死亡時の資産処理などのゲームルールは未決定であり、[ゲームループとポータル遷移](game-loop.md)と[ゲームルール](game-rules.md)を参照する。

## 換金と買い取り

アノマリーアイテムを完全に鑑定できる専門家が常に存在する前提にはしない。買い取り側も「何なのか分からないが、価値がある」と扱い得る。買い取り先にはリサイクルショップ、古物商、質屋、コレクター、研究機関、ブローカー、特殊用途の業者を想定する。

これは社会がアノマリーを完全に理解していることを意味しない。用途、希少性、証拠性、個人的な関心が価値になり得る。世界観上の前提は[アノマリー世界観](../world/anomaly-worldview.md)を参照する。

## 価値の分離とレアルート

一つのアイテムには通常の物品価値、アノマリーとしての価値、特定NPCにのみ生じる価値があり得る。たとえば古いデジタルカメラは、一般店では中古品として低価格でも、コレクターには型番、研究者には異常現象の証拠、特定の依頼主には必要物品として高い価値を持ち得る。

普通に売れば金になる一方、特定NPCへ渡すと別の価値が発生する**アイテム群と取引経路**をレアルートと呼ぶ。レアルート品は、換金ではなく特定の成長・研究へ消費する選択を持ち得る。全てを明示的に説明せず、「これは誰が欲しがるのか」という観察と探索を促す。ただし発見不能な取引を必須の進行条件にはしない。

## コレクター

コレクターはアノマリーの専門家とは限らない。「変なものが好き」「珍しいものを集めている」「似たものを見たことがある」程度の人物も含む。対象の正体を完全には理解していないことを基本とする。

## ビルド／スキル強化の世界内解釈

ゲーム上の強化は、訓練、装備改造、医療処置、アノマリー研究、情報収集、特殊技術の習得、アノマリーへの適応、曝露による変化など、複数の解釈を許容する。「スキルポイントを消費して能力が上がる」というメタ的説明だけにはしない。

通常プレイヤーは、都市ロビーの**アノマリー研究室**でSecure Slotを強化できる。初期状態では総インベントリ20枠のうち4枠がSecure Slotであり、失敗時にも同枠内の物を持ち帰れる。

- **Secure Conversion（確定）**: 通常スロット1枠をSecure Slotへ変換する。レアルート品を消費し、総インベントリ枠数は増えない。
- **Capacity Expansion（確定）**: 総インベントリの枠数自体を増やす強化を設ける。この強化にもSecure Conversionと同種のレアルート品を消費する。

研究室の研究者は、ダンジョンを自ら作ったと主張する件の博士である。アノマリーを完全に説明する専門家ではなく、正体不明の価値を持つ物を受け取り、危険な資産を「確保できる状態」へ変える立場として扱う。博士の主張の真偽とダンジョンの起源は、[アノマリー世界観](../world/anomaly-worldview.md)の意図的な曖昧さを維持する。

交換レート、強化上限、Capacity Expansionで追加された枠が通常／Secureのどちらとして始まるか、入出庫時点は未決定である。

### 課金との関係

レアルート品をRobuxで変換・取得できる経路は**Idea（未採用）**である。導入可否、変換上限、直接購入か代替経路か、ゲームバランスと失敗時の資産リスクへの影響は、経済設計を確定してから別途判断する。現時点で課金システムの実装または採用を意味しない。

ただし能力の由来を完全に説明しない。Player Anomaly の利点やラン中のビルド案は、通常の永続成長と同一視せず、既存の[ゲームループとポータル遷移](game-loop.md)を優先する。

## 未決事項

- 価格、通貨、売却UI、買い取り先ごとの条件。
- レアルートの発見方法と、クエスト報告との競合時のルール。
- Secure ConversionとCapacity Expansionの交換レート、強化上限、追加枠の初期種別、入出庫時点。
- レアルート品のRobux変換・取得経路を採用するかどうか。採用する場合の制約とゲームバランス。
- 永続成長、ラン内ビルド、Player Anomaly中の強化の境界。
