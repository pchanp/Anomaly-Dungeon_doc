# アノマリー世界観

**Status: Draft（草案）**

この文書は、世界観上のアノマリーの捉え方と、社会・ダンジョンとの関係を定義する。個別の Anomaly Entity と Player Anomaly は[アノマリー資料](../anomalies/README.md)で区別して扱う。

## アノマリーの定義

アノマリーとは、あるモデルから逸脱したもの、またはその逸脱によって発生する新しい／不明なモデルである。ここでいうモデルとは、世界が「こう動くはずだ」と人間が暗黙または明示的に想定する規則を指す。

物体は落下する、商品は購入すると減る、所有物には所有者がいる、写真には撮影対象が写る、人間は同時に同じ場所に二人存在しない、死体は自律的に動かない、名前によって対象を区別できる、といった想定は逸脱し得る。

アノマリーは怪物に限らない。生物、物品、空間、現象、情報、人間、プレイヤー自身、社会的ルール、因果関係を含み得る。この定義は、Player Anomaly と Anomaly Entity を同一のゲーム上の型として扱うことを意味しない。

## 社会との関係

社会には、アノマリーに関連する産業、行政、研究、コレクター市場などが存在し得る。ただし、社会全体がアノマリーの正体を理解している状態にはしない。立場ごとに異なるモデルで扱われる。

- 行政にとっては特殊区域。
- 企業にとっては資源。
- 研究者にとっては逸脱現象。
- コレクターにとっては珍品。
- 探索者にとっては仕事。
- 一般市民にとっては、なんとなく危ない場所。

アノマリーを利用することと、理解していることは別である。換金や依頼が成立する理由の設計は[経済と成長](../systems/economy-and-progression.md)、提示の粒度は[世界観の情報提示方針](information-design.md)を参照する。

## ダンジョン

ある研究者が「このアノマリーダンジョンは自分が作った」と自称している。しかし、その主張が真実か、発見しただけか、既存の現象を再現したのか、「作った」という語が正しいのか、研究者自身がアノマリーなのかは確定しない。

ゲーム内では、研究者の主張、記録、第三者の証言などを断片として提示し得る。ダンジョンの探索・帰還・遷移のゲームルールは[ゲームループとポータル遷移](../systems/game-loop.md)を参照する。
