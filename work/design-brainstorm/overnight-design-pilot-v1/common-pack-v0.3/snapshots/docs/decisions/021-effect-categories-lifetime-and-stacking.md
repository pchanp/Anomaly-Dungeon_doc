# 021: 共通Effect分類、保存境界、重ね掛けの既定規則

**Status: Accepted（共通の既定規則として採用。個別Effectと実装は未確定）**

**Date: 2026-10-04**

## 背景

スキル、アイテム、Anomaly Entity、Player Anomalyを接続する共通の記述方法が必要である。一方、永続的な蓄積能力や複雑な数値変動より、Run中のビルド、操作、判断を優位性の中心に置きたい。対象をすべて同一の実体とする設計や、暗黙の倍率合成は避ける。

## 決定

- 共通Effect種別は`Damage`、`Heal`、`StateChange`、`Move`、`InformationChange`、`WorldChange`、`RuleOverride`とする。出現率変更は`WorldChange`に含める。特殊なゲームルール変更は`RuleOverride`に含め、適用対象と優先順位を個別に明記する。
- 作用範囲（個人・Party・Run全体など）と保存境界を分ける。保存境界は「永続」「同一Run中」「同一マップ中」「一時」の四つを基本とする。一時効果の終了条件は固定秒数、距離条件、特定アイテムの干渉などを許し、複数の条件のいずれかが成立したら解除することを既定とする。
- 即時効果はイベントごとに解決する。持続する同一Effectを同じ対象へ再適用した場合は、既定で効果量を足さず1件に保つ。固定秒数の効果は残り時間を更新する。
- 異なるEffectは競合しなければ共存できる。同じ値・行動・世界状態へ作用するときは自動合算・後勝ちにせず、個別の解決規則がなければ競合適用を保留し記録する。加算、回数蓄積、強い方への置換は明示的な例外だけにする。
- `cure`による解除対象は「解除可能な状態異常」に限定する。Exposure、Player Anomaly化、Quest進行、出現率変更、永続解放を包括的に解除しない。

## 判断理由と既存仕様との境界

既定を単一・非加算にすれば、並行するParty行動やアイテム使用の順序が暗黙の数値上昇へ直結しない。例外を個別に記述すれば、特徴的な相互作用を残せる。既存の博士Questの重複なし補正と、発生回数による0.90倍減衰はそれぞれ維持する。既存の開錠成功率やBLOODMOONの自傷などの割合も変更しない。

共通分類は結果の語彙であり、Anomaly Interactionの入力分類、Anomaly EntityとPlayer Anomalyの状態本体、ServerとClientの責務を置き換えない。万能Serviceの即時実装も決定しない。

## 残る判断

異なるEffectがHP、移動速度、出現率、可視性など同じ対象値へ作用するときの優先順位、再適用時刻、Effect IDと出所の識別方法、`RuleOverride`の処理順、個別の数値バランスは未決定である。
