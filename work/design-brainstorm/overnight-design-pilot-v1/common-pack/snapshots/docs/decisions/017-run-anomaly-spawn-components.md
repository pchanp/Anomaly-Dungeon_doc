# 017: Run単位のアノマリー出現コンポーネント

**Status: Accepted（採用）**
**Date: 2026-10-02**

## 背景

博士Questの対象が選択マップの候補外である場合、他候補へ補正を振り替えると、Questと無関係なアノマリーの発生理由が不明瞭になる。また、同種アノマリーを常に1体へ固定すると、複数出現を性質とするアノマリーや、アイテムによるRunの変化を扱えない。

## 決定内容

### 候補外の博士Quest対象

開始時に固定した博士Quest対象が選択マップの出現候補に存在しない場合、その対象への1.40倍補正は適用しない。補正を他候補へ移す、全候補へ分配する、別報酬を与える、といった代替効果は発生しない。

### 同時出現数コンポーネント

各アノマリーは、同種が同時に存在できる数を表す**同時出現数コンポーネント**を持つ。

- 標準値は1とする。
- 複数同時出現を性質とするアノマリーは、個別に別の値を持てる。
- このコンポーネントが、同種アノマリー1体を原則とする制約の例外を表す。

アノマリーが解決・消滅した後に同時出現数の枠を再び使えるかは、今回決めない。

### Run単位の変動

特定アイテムは、アノマリー出現に関するコンポーネントをRun単位で変動させ得る。対象には少なくとも、個別出現確率と同時出現数が含まれ得る。

- 変動はサーバーがRun状態として確定する。
- 変動は個人のクライアント表示や所持だけに閉じない。
- Run終了時に破棄し、永続成長には直接持ち越さない。
- 具体的なアイテム、変更するコンポーネント、値の重ね方は別途決める。

## 影響

- Anomaly Systemは、アノマリーごとの基礎定義と、Run中に変動する出現状態を分離する必要がある。
- Item Interactionは、通常の所持・使用結果に加え、サーバー側Run状態の変更を起こし得る。
- 博士Quest補正、発生ごとの0.90倍減衰、同時出現数、アイテム変動を同じ出現計算で評価する必要がある。

## 未決事項

- 同時出現数コンポーネントのSystem ID、データ形式、既存プロトタイプへの適用。
- アノマリー解決・消滅後の同時出現枠の扱い。
- 変動アイテムの一覧、各変更値、重ね方、解除条件。
- 出現補正を評価する正確な順序と、候補が複数成立した場合の選出方法。
