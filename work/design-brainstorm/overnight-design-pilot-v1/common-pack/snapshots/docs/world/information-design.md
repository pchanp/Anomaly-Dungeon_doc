# 世界観の情報提示方針

**Status: Draft（草案）**

この文書は、プレイヤーに明示するゲーム情報と、意図的に断片化・未解決として扱う世界情報の境界を定義する。

## 中心原則

**ルールは明確、意味は曖昧。**

プレイヤーが遊ぶために必要な情報は明確にする。一方で、世界の歴史、原因、真相は説明しすぎない。クエストの目的は明確にし、対象の正体や必要とされる理由は不明であり得る。

### 明確にするもの

- クエストの目的と報酬。
- アイテムとスキルの基本的なゲーム効果。
- ダンジョンへの行き方と帰還方法。
- 基本操作と、ランを安全に判断するためのルール。

### 意図的に曖昧にするもの

- ダンジョンの起源、研究者の本当の目的、アノマリー発生の原因。
- 世界全体におけるアノマリーの位置付けと、世界そのものが正常かどうか。
- アイテムの本当の用途。
- NPC がアノマリーをどこまで認識・理解しているか。

## 「説明」ではなく「痕跡」

長い設定説明を基本手段にしない。NPCの会話、求人票、商品説明、研究記録、写真、古い端末、廃施設、クエスト内容、コレクターの発言、行政資料、噂、アイテム、環境そのものから、プレイヤーが推測できるようにする。

作者側で詳細な設定を保持することは妨げないが、ゲーム内で提示する情報は断片的でよい。NPCは世界設定を説明する役ではなく、世界の中で生活し必要なことを話す存在として扱う。

## 適用先

- 依頼主は目的・報酬・最低限の事情を伝え、起源や真相を解説しない。詳細は[クエスト](../systems/quests.md)を参照する。
- 2D都市マップと施設内3Dは、説明画面ではなく世界の通常性に触れる入口として用いる。詳細は[ロビー／ワールドマップ](../systems/lobby-world-map.md)を参照する。
- アノマリーを扱う社会の複数の見方を、断定的な正解に統合しない。詳細は[アノマリー世界観](anomaly-worldview.md)を参照する。
