# 004: 都市入口と情報提示の設計方針

**Status: Draft（草案）**
**Date: 2026-09-29**

## 背景

既存のラン設計は「依頼 -> 探索 -> 帰還 -> 報酬 -> 換金・強化」を基本循環としているが、依頼を受ける場所、社会との接点、世界観を説明しすぎない提示方法は未整理だった。また、実装済みのロビーはプロトタイプであり、将来の都市入口としての表現を決めるものではない。

## 現時点の判断

- ロビーは待合室ではなく、探索者が生活する架空都市への入口として扱う。
- 2Dワールドマップから小規模な施設内3Dへ移り、出発準備を経てダンジョンへ入る階層を基本案とする。
- 舞台は現実の日本ではない架空世界とし、平成的な都市文化の記憶を抽出して用いる。
- ルールとクエストの目的は明確にし、世界の原因・真相・対象の意味は断片的に扱う。
- 社会はアノマリーを利用し得るが、完全には理解しない。NPCを設定説明のための役にはしない。

## 理由

- 短い開始導線を保ちながら、機能選択を世界の中で行う感覚を作るため。
- 2D街、生活空間としての施設、異常なダンジョンを分けることで、世界の通常性から異常性への移行を表現するため。
- 正解を早期に固定せず、探索・アイテム・依頼・環境からプレイヤーが推測できる余地を残すため。

## 影響と未決事項

- 既存のラン、Return、Transition、Player Anomaly、Secure Slotの草案は変更しない。新しい都市入口は、それらのラン外側を接続する設計である。
- 2Dマップ、施設一覧、遷移演出、各施設の実装、取引と永続成長の数値・データモデルは未決定である。
- 現在の実装済みロビーを置換する判断ではない。実装着手時には現在のプレース構造と別途照合する。
