# アセット制作パイプライン

**Status: Draft（草案）**

## 目的

3Dアセットを作成・調整し、Roblox Studio上で検証可能な状態へ導入するまでの共通工程を定義します。

## 標準工程

1. 用途とゲーム上の要件を関連仕様で確認する。
2. モデルを制作または生成する。
3. Blenderで形状、スケール、法線、マテリアル、命名を確認する。
4. キャラクターの場合はRigとSkin Weightを確認する。
5. 必要なアニメーションを制作する。
6. Roblox向けFBXとして出力する。
7. Roblox StudioへImportし、見た目、スケール、Rig、再生結果を確認する。
8. 利用した元データ、出力物、既知の問題を記録する。

## 完了条件

- Roblox Studio上で意図した用途に配置できる。
- 見た目、向き、スケール、Rigが破綻していない。
- アニメーション対象では、実ゲーム相当のRigで再生確認できる。
- 未解決事項が文書化されている。
