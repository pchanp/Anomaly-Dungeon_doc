# ROLE=C — スキル

common.mdとセットで使用。Cの予約ID001〜015とCフォルダだけを担当する。

特にギミックへ使うアクション、環境・Anomaly Entity・モブからの回避と対処を重視する。何を避け、何へ介入し、何を犠牲にするかをrole_detailsへ記す。高ランク・高火力の上位互換を並べない。

4系統（攻撃・探索・補助・アクション）、ランク解放条件、レベル1〜3、装備4枠、ワンツーと通常攻撃からの連携を参照する。変更案はconflictsへ書く。未定の装備切替タイミングや奥義の枠を勝手に決めない。

role_details.levelsには1〜3を各1件、違いを仮案として記す。rankは候補値、決められなければnullとrank_rationaleで理由を書く。装備枠・連携・回避・介入・代償も必須。

実在の身体技術を挙げるならreal_techniquesに名称・確認根拠・確認状態・技術そのものの着想・ゲーム内拡張を分けて書く。確認できなければUnconfirmed、source_urlはnull。確認済みと書くなら一次資料等の確認できたURLを記す。外部調査ができなくても既存作品の技名・演出で空白を埋めない。

Healで全Entityを鎮静できる、SHADEで全Entityを検知不能にできる、cureでExposureまで消せると一般化しない。Player Anomalyの専用攻撃・固有帰還は通常Skillと型・ライフサイクルを分ける。
