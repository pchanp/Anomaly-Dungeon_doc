# 009: TSUTAYAを「閉店直後のアーカイブ」として再構成する

**Status: Draft（ソース反映済み・Studio未確認）**
**Date: 2026-09-30**

## 背景

`TSUTAYA` は、最小Runで8月31日と並ぶ探索先である。従来の生成器は通路接続と探索上の遮蔽を優先しており、青い区画看板、棚フレーム、均質な部屋照明によるブロックアウトとして読まれやすかった。

参照した閉店前のレンタル店には、密集した背表紙、レジ、CRT、ジャンルや販促の断片、蛍光灯の均一で冷たい光がある。一方、放棄後の店舗には、空になった区画、少数の落下物、消えた照明、作業途中の物がある。この二つを混同せず、最初は前者を主にし、後者を少量だけ重ねる。

## 決定内容

### 基準状態

マップの基準状態は、**閉店直後だが、誰も回収に来ないアーカイブ**とする。

- 棚は大半が残り、背表紙の密度で空間をつくる。
- 店頭は最も明るく、レジ・会員端末・販促面が店舗としての記憶を残す。
- 放送室と返却作業場は暗く、作業物や未整理ケースが残る。
- 落下ケースと欠番は少数に留める。店全体を瓦礫にしない。

これにより、探索開始時点で「何があった店か」を読める一方、Archive、CRT、店内放送の相互作用によって現実との境界が揺らぐ余地を残す。

### 将来の荒廃表現

埃、剥離、漏水、カビ、棚崩れ、破損照明、散乱物は、後からMaterial／Texture／Decal／Particle／マップイベントの層として追加する。棚、レジ、作業場、照明の構造自体を荒廃表現へ固定しない。

8月32日のような全体フェーズをこのマップへ追加することは、今回決めない。

### 世界観上の扱い

`TSUTAYA` は現在の安定Map IDであり、今回変更しない。将来プレイヤーへ表示するブランド・外観名は、実在商標と直接対応させるかを別途判断する。架空世界の街並みとしては英語・抽象語・架空名を混ぜ、現実の日本の店舗をそのまま再現しない。

## 実装範囲

- 棚へ背表紙と欠番を追加する。
- 店頭へレジ、レシート、色褪せた販促面を追加する。
- 返却作業場へカートと未整理ケースを追加する。
- 店頭・売場・放送室・作業場で蛍光灯の生存率を分ける。
- 既存の`LINKS`、通路幅、Prompt、Archive UI、CRT、試聴、Quest、出口条件は変更しない。

## 検証が必要な事項

- 背表紙、落下ケース、レジ小物が通路、Prompt、Raycast、プレイヤー移動を妨げないこと。
- 棚の追加Part数とPointLight数がクライアント負荷を悪化させないこと。
- 店頭が明るすぎて廃店舗感を失わず、奥が暗すぎて探索不能にもならないこと。
- 既存の`ArchiveShelf`と追加の視覚棚を混同しないこと。
- StudioプレースがGitソースと一致していること。現時点では画面取得によるStudio確認は未完了。
