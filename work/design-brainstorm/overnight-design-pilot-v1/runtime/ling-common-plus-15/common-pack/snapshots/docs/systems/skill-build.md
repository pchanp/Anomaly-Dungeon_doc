# 通常スキルとビルド

**Status: Draft（個別スキルは設計案、取得・成長の基本則は合意済み）**

この文書は、通常スキルの系統、解放と強化、装備構成、現時点の個別スキル案を記録する。実装済みスキルの一覧ではない。Player AnomalyやAnomaly Entityに由来する専用スキルの取得は、[アノマリー固有スキルの設計判断](../decisions/012-anomaly-linked-skill-acquisition.md)と区別する。

## 系統・ランク・レベル

通常スキルの系統は**攻撃・探索・補助・アクション**の4つとする。攻撃は直接攻撃、探索はアイテムスタックの解放・検知・スニーク、補助は回復・Buff・Debuff・状態異常攻撃、アクションは高速移動・Teleport・Grapplingなどの移動やギミックへの介入を扱う。効果が複数の役割を持っても、個別スキルの所属系統は一つに定める。

- **スキル解放**: 未修得のスキルをレベル1で修得する。
- **スキル強化**: 修得済みのそのスキルのレベルを1上げる。最大レベルは3。
- **スキルランク**: 解放可能なスキルの段階であり、個別スキルのレベルとは別。各系統で次ランクのスキルを解放するには、直前ランクのスキルを3つ解放し、そのうち1つ以上をレベル3にする。両条件が必要。
- **奥義**: 系統を横断するスキル。ランクごとの通常スキル強化状況によって取得可能にするが、具体的な組み合わせは各ランクのスキルが出揃ってから決める。奥義は通常スキルの「直前ランクの3スキル」には数えない。
- **成長資源**: 汎用スキルレアルート品を通常スキルの解放・強化と奥義取得に使用する。必要数や交換レートは未決定。アノマリー固有品やスロット用レアルート品とは用途を分ける。

4つの装備枠を想定する。修得済みスキルの総数と装備枠数は別だが、装備切替の場所・タイミング、奥義・パッシブ・アノマリー専用スキルが枠を占有する条件は未決定。現行の3スキル実装は[現在の実装状況](current-implementation.md)を参照する。

スキル解放・強化は既存の成長要素として維持する一方、永続的な数値蓄積だけでRunの優位性が決まらないよう、4枠の構成、操作、判断を重視する。効果の共通分類と持続・重ね掛けの既定規則は[共通Effectと保存境界](effect-components.md)を参照する。個別スキルの数値バランスは未決定。

## 通常攻撃と連携

- 素手の通常攻撃は**ワンツー**。武器を持つ場合は武器に応じたアクションへ変わる。
- 4つの装備枠すべてが攻撃系スキルの場合、攻撃系の奥義も含めてフルアタック構成とする。この構成では素手の通常攻撃が**ワンツー→アッパー→回し蹴り**の4連撃になり、回し蹴りに小ノックバックが付く。武器装備時のフルアタック動作は未決定。
- 通常攻撃からスキルへ、スキルから別のスキルへ連携できる。入力受付時間、キャンセル可能時点、硬直、同一スキルの再連携、スタミナ等のコストは未決定。

## 攻撃系

| ランク | 名称 | 効果案 |
| --- | --- | --- |
| 1 | 纏絲勁（tensikei） | 脱力と張りで全身をつなぐ攻防一体の突き。小威力の攻撃をParryしながら中ダメージを与え、対象を0.5秒Stunさせ、さらに遅延して体内からの衝撃による追加小ダメージ。 |
| 1 | 平安初段（heian-shodan） | 前後左右に移動しながらParryと攻撃を行う21連撃。各Hitは小ダメージ。実行中は通常移動できないため、乱戦で働く一方、強敵には隙が生じる。 |
| 2 | SS（StealStep）サイドキック | 相手の虚をつく運足で瞬時に接近して横蹴り。中ダメージ、大ノックバック。コンボの締めに利用できる。 |
| 2 | COBRA | 再使用または他スキルの発動まで続く構え。クールタイムなしで切り替え、通常攻撃を中ダメージ・小ノックバックの連射可能な前蹴りへ変更する。 |
| 2 | BLOODMOON | 爪についた血を硬化して刃状に飛ばす。中距離・狭幅・中ダメージ、短いクールタイム。3連続発動すると自身のHPが1割減る。 |

纏絲勁のParry可能な「小威力」の境界、平安初段の21Hitの対象配分とParry区間、COBRAの入力間隔、BLOODMOONの連続判定のリセット条件およびHP1割の基準は未決定。

## 整合性と次に決めること

- 各系統のランク1はまだ3案に達していないため、現行案だけではランク2解放条件を満たせない。ランク2案は先行する設計案として保持する。
- 攻撃・状態異常・遅延ダメージ・多段Hitを含むPvPでは、[ゲームルール](game-rules.md)の通常プレイヤー同士HP 80%下限と、Player Anomalyとの相互キル可能ルールを各Hit・効果へ適用する必要がある。
- ダメージの小／中／大、Stunの中、Parry、無敵、Knockback、Cooldown、連携窓は数値未定。数値を補って実装済み仕様にしてはならない。
- 今回の名称は個別スキル案の呼称であり、安定したSystem IDは未決定。表示名の変更と実装IDの変更を同一視しない。
