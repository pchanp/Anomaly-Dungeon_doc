# 008: 8月31日の景観構成を、ブロックアウトから夏の谷へ寄せる

**Status: Draft（ソース反映済み・Studio未確認）**
**Date: 2026-09-30**

## 背景

最小Runの候補マップである8月31日は、地形・湖・フェーズ時計の再設計後も、大きな単色Part、同じ形の木、説明用看板に視覚が分散しやすかった。谷を歩く体験としての遠景、水辺、生活の痕跡の優先順位が弱く、夏の終わりの通常性から8月32日の異常へ移る対比を作りにくい状態だった。

本記録は、特定の現実都市・地域、または既存作品の背景を再現するものではない。[舞台設定](../world/setting.md)に従い、平成的な夏の郊外・水辺・丘上の集合住宅から抽出した景観の記号を、架空世界の谷として再構成する。

## 決定内容

### 視線の順序

景観の主な順序を、次のように置く。

```text
バス停の前景
    -> 道と送電線の方向
    -> 集落・田・河原の生活の密度
    -> 水面と稜線の余白
    -> 丘上の団地（8/32で意味が変わる遠景）
```

地図記号や大きな説明看板ではなく、道路、電線、水面、建物の輪郭を方向づけの手掛かりとする。必要なQuestや操作情報は既存のPromptを維持し、景観要素へ新たなゲームルールを持ち込まない。

### 植生と水辺

- 森は同一の直方体Canopyの反復ではなく、少数の球状Canopyを重ねた針葉樹の量塊として扱う。
- 集落、バス停、田の周囲には広葉樹と夏草を少数配置し、道路沿いに生活の密度を寄せる。
- 湖畔は新しい建築や報酬を置かず、葦と石で水際をつくる。水面は探索先を説明するUIではなく、遠景の余白として扱う。
- 田は水面だけで終えず、低い草のまとまりで季節感を出す。

### 人工物

- 送電柱には低密度の電線を追加し、谷の入口から集落へ向かう視線をつなぐ。
- 集落の建物は道路沿いに日除け・植栽を置き、単純な箱の列に見えないようにする。
- 団地は谷を見下ろす遠景マーカーとし、8/32専用の増築物とは別に、前面の広場と植栽で輪郭を残す。
- 世界内の景観サインは英語・抽象語を混ぜ、現実の日本の制度や地理をそのまま再現しない。

## 実装範囲

`AugustGenerator` の既存のMap ID、ゾーン、Trail、Prompt、8/32の状態遷移、Return条件、地形高関数は変更しない。追加するのは、景観の小物と既存Canopyの形状のみとする。

`TSUTAYA` は同じ最小Run候補としてソース構造を確認したが、今回は室内マップの通路・棚・照明の挙動を変更しない。室内の視線・質感・アーカイブ表現は別の判断として扱う。

## 検証が必要な事項

- 追加した草・樹木・電線がTrail、Prompt、カメラ、移動を遮らないこと。
- 既に多い地表タイルに景観小物を加えたときのフレームレートとStreaming挙動。
- DAY、EVENING、NIGHT、AUG_32の各Tintで、水面・植生・団地の輪郭が読めること。
- 入口から湖と団地が意図した遠景として読めるか、また8/32で団地前への移動後に別の意味を持つか。
- StudioプレースがGitソースと一致していること。現在、この作業環境ではStudioの画面取得に失敗しており、実画面の確認は未完了である。
