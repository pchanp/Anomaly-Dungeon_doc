# 014: Quest枠、Discovery、博士Questによる研究解放

**Status: Accepted（採用）**
**Date: 2026-10-01**

## 背景

Questはラン中の明確な目的、DiscoveryはFILEやアノマリーを発見した記録として分離する方針があった。しかし、同時に持てるQuest数、博士Questとその他Questの役割、Quest外で先に得た固有品をいつ専用スキルへ交換できるかは未確定だった。

博士Questは、アノマリー相互作用の導線である。Questを未受注のまま偶然固有品を得る可能性を否定せず、発見の偶然性と意図的な調査の双方を成立させる。

## 決定内容

### Quest枠

同時に受注できるQuestは合計4件とする。

| 区分 | 上限 | 役割 |
| --- | ---: | --- |
| 博士Quest | 1件 | 対応アノマリーの調査・相互作用と研究解放 |
| その他Quest | 3件 | 市民、施設、業者などからの具体的な依頼 |
| 合計 | 4件 | 同時に受注できるQuest全体の上限 |

博士Questを受注中は、対応アノマリーの**Run内個別出現確率**を基礎値の1.40倍へ上げる。これは都市ロビーからのマップ抽選確率や、候補全体の重みを変えない。

同一マップでアノマリーが1体発生するごとに、すべての候補の個別出現確率は0.90倍になる。発生済み数を`n`とすると、基礎値への減衰は`0.90^n`である。博士Quest対象には、これに加えて1.40倍を適用する。同種アノマリーは一部の例外を除き同一マップに1体だけ発生する。

### Discovery

Discoveryは、FILE、NPC、環境、アノマリー、関連アイテムなどを発見・認識した記録である。

- Questではないため、5件のQuest枠を消費しない。
- Questの達成・失敗・報酬とは別に扱う。
- Discoveryの保存期間、UI、博士Quest解放との正確な関係は今回確定しない。

### 固有品と専用スキルの交換

アノマリー相互作用で得る固有品は、取得時に対応する博士Questを受注している必要はない。

対応する博士Questが解放された後、プレイヤーがそのQuestを受注中であれば、固有品を研究室で専用スキルへ交換できる。Questの完了・報告は交換の条件にしない。

したがって、偶然得た固有品も、後から博士Questを受注して即座にスキル化できる。一方、Questを受注すれば対象アノマリーの出現率が上がるため、狙って相互作用を起こす調査導線にもなる。

## 影響

- Questデータは、区分、同時受注数、受注状態、対応アノマリー、固有スキル交換の解放条件を表す必要がある。
- DiscoveryはQuest状態と分離したデータモデルとUIを必要とする。
- アノマリー出現抽選は、マップ抽選後に受注中の博士Questを入力として扱う必要がある。
- 研究室の交換UIは、固有品の所持だけでなく対応Questの受注状態を確認する必要がある。

## 未決事項

- 同種アノマリー1体制限の例外。
- Party内で複数の博士Questが受注されている場合、どのQuestを出現計算へ入力するか。
- Questを受注・放棄・完了・失敗したときの固有スキル交換可否。
- 研究対象外のレアアノマリーに対応する博士Questの解放条件。
- Discoveryの保存、UI、FILEや実績とのデータ境界。
- 同一Questや同一固有品を反復した場合の報酬・スキル強化。
