# 世界観と型の不変条件

**Status: Draft（夜間候補をレビューするための境界）**

下記は今回の生成に適用するユーザー指定の境界。参照MDのDraftがゲーム全体の採用済み設定へ変わる意味ではない。

| ID | 維持する境界 | 根拠 |
| --- | --- | --- |
| INV-01 | ルールは明確、世界の意味は曖昧。操作・対処・終了は具体的に、原因・真相は仮説として留める。 | world/information-design.md |
| INV-02 | 現実の日本、実際の関ヶ原、実在TSUTAYA店舗、既存作品をそのまま再現しない。 | world/setting.md、判断009、ユーザー指示 |
| INV-03 | 世界・ダンジョンの起源、Anomalyの正体、博士の真意を正典として断定しない。 | world/anomaly-worldview.md |
| INV-04 | Anomaly Entity、Player Anomaly、通常NPC、モブ敵の役割と状態本体を分ける。NPCが奇妙でも自動的にEntityにしない。 | anomalies/README.md、判断019 |
| INV-05 | システムID・ゲーム内表示名・今回の候補IDを分ける。既存固有名を勝手に改名しない。 | AGENTS.md |
| INV-06 | マップ案・正式レイアウト・建物構造を新規提案しない。SVGの配置は作用関係の模式図であり、地図ではない。 | ユーザー指示 |
| INV-07 | 都市ロビーの博士の研究室とダンジョン内の研究所を分ける。元同僚Questの装置の正体・人物の行方・処分の真偽を確定しない。 | whisper.md、判断018 |
| INV-08 | 永続数値の蓄積だけで優位を決めず、Run中のビルド・操作・観察・判断に価値を置く。 | effect-components.md、判断021 |
| INV-09 | 共通Effect分類・保存境界・重ね掛けを守る。解除可能な状態異常以外をcureで万能解除しない。 | effect-components.md、判断021 |
| INV-10 | Serverの共有事実とClientの提示／認識差を分ける。 | game-rules.md、anomaly-interaction.md |
| INV-11 | 現行2マップの最小Runの実装範囲・採用状態を候補で変更しない。 | 判断005、current-implementation.md |

候補JSONの `worldview.invariants_checked` には全IDを記す。これは自己確認であって、検証器が内容の整合性を証明するものではない。

意図的なデペイズマンは歓迎する。`worldview` に「何を異化したか」「この世界で成立し得る理由」「あえて確定しない意味」を書く。異化が不要な案なら、不要な理由を書く。新しい原因・組織史・正体を創作して理由にしない。

仕様の変更案は `conflicts` に衝突文書・現行記述・変更案・補正できる理由・採用時の判断を書けば候補として残せる。ただし真相の断定、型の混同、正式な新マップ／構造の確定は、単に「矛盾あり」と書いても許容しない。差し戻し対象として内容レビューへ送る。
