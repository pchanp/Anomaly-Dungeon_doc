# 011: レアルート品の分類と取得経路

**Status: Accepted（採用）**
**Date: 2026-10-01**

## 背景

レアルート品は、通常換金とは別の価値を持つアイテム群であり、研究室での永続成長へ消費できる。[010](010-real-route-secure-slot-progression.md)では、スロット強化の消費先と研究室を決めたが、レアルート品の種類と取得経路は未決定だった。

単なる敵の低確率ドロップやCreditsとの直接交換にすると、探索・観察・アノマリー相互作用との接続が弱くなる。一方、隠し要素だけにすると成長資源としてのルールを理解できない。

## 決定内容

### 汎用レアルート品とアノマリー固有の交換品

汎用レアルート品を、少なくとも以下の2系統に分ける。これとは別に、アノマリーの一部または関連アイテムを、対応する専用スキルだけと交換する固有の交換品として扱う。

| 系統 | 用途 | 相対的な入手性 |
| --- | --- | --- |
| 汎用スキルレアルート品 | 博士の過去の研究成果として抽出された、探索・戦闘に役立つ汎用スキルの獲得・強化。交換対象を選べる | スロット用より出やすい |
| スロットレアルート品 | Secure Conversion、Capacity Expansion | 汎用スキル用より希少 |

具体的なItem ID、確率、必要数、段階ごとの増加量は今回決めない。

### 取得経路

レアルート品は、主に次の経路で得られる。

1. アノマリー相互作用の結果。Invisibleの発見、巨人の沈静化など、観察・探索・通常アクションによる相互作用によって、対応する一部または関連アイテムを出現させる。この固有品は対応する専用スキルだけと交換する。同一Runのパーティ全員が獲得する。
2. 低難度以外のQuest報酬。主に汎用スキルレアルート品とスロットレアルート品を扱う。
3. チュートリアルQuestを設ける場合の報酬。ここでは研究室での汎用スキルまたはスロット強化の交換ルールを明確に伝える。

博士のQuestは、通常の研究対象となるアノマリーを発見し、調査、撃退、沈静化、NPCへのアノマリー的干渉などの相互作用を目的にする。固有品はQuest報告の直接報酬ではなく、相互作用成立時に出現する。FILEやNPCなどから現れる博士の研究対象外のレアアノマリーでも、同様の相互作用で固有スキルを得られ得る。

チュートリアルで明確にするのは、「どの系統のレアルート品を、研究室でどの強化へ使えるか」というゲームルールである。アノマリーの正体、レアルート品の由来、研究者の主張を説明し尽くさない。

## 影響

- アノマリー相互作用は、戦闘・状態変化だけでなく、固有スキル取得の契機にもなり得る。
- Questの難度区分と報酬モデルは、レアルート品の供給量に影響するため、Questデータモデル設計時に必要になる。
- スロット強化用の希少さは、失敗時に持ち帰れる枠を増やす価値と対応する。
- アイテム基盤を実装する際は、少なくとも系統、取得元、通常換金との関係、研究室での交換先、固有品と専用スキルの対応を表せる必要がある。

## 未決事項

- 各レアルート品と固有品の名称、Item ID、外見、通常換金額、スタック規則。
- 相対的な入手性を実際の確率・報酬量へ落とす方法。
- Questの難度区分と、どの依頼がどの系統を報酬にできるか。
- InvisibleのシステムID・ゲーム内名称と、発見時に得る固有品・専用スキルの正確な条件。
- Mad Stomperの花の胞子に対応する専用スキルの名称・効果。
- 固有品のParty配分で、切断者・条件成立時に不在の参加者をどう扱うか。
