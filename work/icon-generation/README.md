# アイコン生成の作業場所

**Status: Implemented（実装済み・Prototypeの作業領域）**

OpenCodeでプロンプトを3並走して準備し、MacのDraw Things（SDXL）で生成した候補を比較する場所です。対象・画風・ゲーム内アイコンサイズ・担当ごとの課題は未確定です。画像やレビューは仕様の正本ではありません。

| フォルダ | 用途 |
| --- | --- |
| `A/requests/`・`B/requests/`・`C/requests/` | 担当ごとの生成依頼JSON。 |
| `A/images/`・`B/images/`・`C/images/` | 完成画像と生成情報。自動で一覧に載る。 |
| `.runtime/` | 共有キュー、レビューDB、アクセスキー、サムネイル、接続ログ。Git対象外。 |

操作の正本は [`tools/icon-gallery/README.md`](../../tools/icon-gallery/README.md) です。

制作ワークショップでは **W01** に対応します。[共通契約](../../docs/production/workshop/shared/handoff.md)と [W01-01 評価準備](tasks/W01-01/TASK.md)を参照してください。既存A/B/Cレーンと保存方式を維持し、タスク・試行記録から参照します。

2026-10-15の [SHADE評価資料](tasks/W01-01/runs/review-20261015/README.md)では、既存20枚を固定したオフライン比較ページを準備しています。画像生成・正式採用は行わず、実ブラウザ表示と人間レビューは未確認です。

初回の対象・担当配分・OpenCode接続確認・プロンプト・生成記録は [`SHADE 5枚の試作`](shade-20261014/README.md) に分離しています。画風や正式アセット採用の決定ではありません。

追加の [`SHADE 20枚・フォックス横Bの視覚比較`](shade-20261014-fox20/README.md) は、英語のビジュアル指示から作成した候補です。ABCへの指示・画像プロンプト・各案の注記は英語、ユーザー向けのサマリは日本語とします。スキルの性能説明を、そのまま画像プロンプトへ渡しません。

リポジトリのルートで外出先ビューを起動:

```sh
python3 tools/icon-gallery/share.py
```

Draw ThingsのHTTP APIを有効にした後、別ターミナルで生成ワーカーを起動:

```sh
python3 tools/icon-gallery/jobs.py work --url http://127.0.0.1:7860
```

OpenCodeの3セッションには、それぞれこのフォルダの `A/`、`B/`、`C/` を作業ディレクトリとして指定してください。起動時に無料モデルであることを確認し、各セッションへ具体的な対象・件数・終了条件を伝えます。課題が未指定のまま自動生成は始めません。

生成画像と担当の依頼JSONは初期状態ではGit対象外です。残したい候補を確認してから明示的にGitへ追加してください。アクセスキーとDBはコミットしません。
