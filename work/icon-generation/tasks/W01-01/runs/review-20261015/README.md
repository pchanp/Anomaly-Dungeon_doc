# W01：SHADE候補の評価入口

**Status: Implemented（評価資料）／ブラウザ実表示・人間評価はUnconfirmed（未確認）**

[評価ページを開く](review.html)。既存20枚を元画像のまま埋め込んだローカルHTMLで、ネット接続・サーバー起動は不要です。新規画像は生成していません。約数十MBのため、開くまで時間がかかる場合があります。

## 評価する順序

1. ブラウザのズームを100%にする。それ以外なら倍率をメモへ記録する。ページに画像が20枚読み込まれるか確認する。
2. 必要なら候補ラベルを隠し、画像から何の動作に見えるかを記入する。
3. 「今回の目標と評価条件」を開き、横方向の姿勢・独立した残像・不要な衣装／背景等を別々に評価する。
4. 32／48／64pxで動作の識別性を確認する。周辺背景を切り替えて比較する。画像の背景は不透明のままで、透過合成の検証ではない。
5. 残したい要素・直したい要素をメモし、採用候補／修正したい／見送りを提案する。正式採用を決定する操作ではない。
6. 評価者を入力し「評価をJSONで保存」を押す。ダウンロードが完了したことと保存先を確認する。ページを閉じる前に保存する。

評価は明暗背景ごとに分けて保持します。切り替えると、その背景の入力へ戻ります。未評価項目は空欄のままJSONへ出力され、Passにはなりません。評価JSONの再読み込み機能はなく、ページを再度開いても入力は復元されません。既存ギャラリーのDBには書き込みません。

## 固定した資料

- [4層のBrief](brief.en.md)：仕様の事実と暫定描画を分離。
- [入力一覧](inputs.json)：20画像・生成依頼・参照文書のSHA256、Seed、方式。
- [検証記録](verification.json)、[実施結果](RESULT.md)。
- [3枚の暫定観察](observations.en.md)：全20枚を採点した結果ではない。

評価ページは原PNGを埋め込むため、元レーンのファイルが後から変わっても今回の画像は変わりません。大きいHTMLと人間のレビューJSONはこの試行の `.gitignore` でGit対象外です。別端末へ渡す場合はHTMLを明示的にコピーし、入力一覧の版と合わせて管理してください。外部公開はしていません。

生成時の原条件・出典は既存batchの記録を参照します。制作候補の利用条件・正式採用は未判断です。再構築は `build_review.py` を参照しますが、既存review.htmlがある場合は停止します。別条件を試すときは新しい試行へ保存してください。
