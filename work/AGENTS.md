# 制作作業の共通規約

ルートの `AGENTS.md` と `README.md` に追加して適用する。ワークショップの入口は [制作ワークショップ](../docs/production/workshop/README.md)。部屋固有の指示を読み、既存の作業場所・レーン・保存形式を尊重する。

- 作業開始前にタスクの目的、参照仕様、入力版、変更可能範囲、受け入れ条件、件数・費用・再試行の上限を確認する。不足した判断は記録し、依存する実行を開始しない。
- タスクID・試行ID・成果物版とゲームのSystem IDを分ける。System IDが未決定なら空欄または未確定とし、作業IDで代用しない。
- 原本を保持し、編集・出力は新しい試行または版へ保存する。他の部屋・担当の成果物を無断で変更しない。担当範囲外の変更が必要なら対象と理由を先に明示する。
- GPU・Studio等の共有資源は統括担当が使用状況を確認して実行を割り当てる。Markdownの担当欄を排他ロックとみなさない。既存ツールのキュー・ロックを迂回しない。
- 単一実行を初期運用の基準とする。既存の明示的に割り当てられたW01レーン運用は維持する。新たな並列実行・バックエンド変更を自動で開始しない。
- 要求したツール／モデルと実際に観測したものを区別する。外部ジョブID・設定・生成条件を残し、タイムアウトや結果不明を成功と扱わない。再投入前に外部側の状態と保存済み出力を確認する。
- 結果と証拠を [受け渡し規約](../docs/production/workshop/shared/handoff.md) に従って保存する。生成成功、検証Pass、次工程への受け渡し、美術・仕様の正式採用は別々に記録する。
- エージェントは機械検証と候補評価を記録できる。人間の美術・仕様判断を代行して正式採用にしない。未検証は未検証として引き渡す。
- Workboardの状態は統括担当が更新する。実行担当は結果と更新案を返す。`Ready`でもタスクに明記した権限・費用・公開範囲を超えない。
- アクセスキー、認証情報、非公開共有URL、実行DB・ログ等を共通文書やGitへ追加しない。既存の除外設定を維持し、バイナリの保存先・バックアップは別途確認する。
- 本文は日本語を基本とする。W01の英語Brief・描画指示・引き継ぎ等、明示済みの部屋固有言語方針は維持する。

本規約は作業指示であり、アクセス権やプロセス排他を強制する実装ではない。
