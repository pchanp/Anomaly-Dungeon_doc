## 共通の描画指示

1. `AGENTS.md`、`README.md`、対象の `docs/world/`、`docs/systems/`、`docs/anomalies/`、`docs/decisions/` を先に読む。
2. 仕様に書かれた視覚要素と、画を成立させるための仮案を分ける。後者で世界の謎やシステムルールを確定しない。
3. 各対象を実際に見られる2D画像またはHTML/SVGとして残す。根拠・仮案・未確定要素を併記する。
4. 実在の都市、国家、商標、既存作品の固有意匠をそのまま再現しない。特にTSUTAYAは現在のMap IDであり、プレイヤー向けの店名を確定したものではない。
5. Anomaly Entity、Player Anomaly、認知アノマリーの横断的な設計を混同しない。

## レビュー時に見る点

- 架空世界が現実の日本または中世ファンタジーそのものに寄りすぎていないか。
- アノマリーの現象や認識差が、説明的な怪物図鑑に変わっていないか。
