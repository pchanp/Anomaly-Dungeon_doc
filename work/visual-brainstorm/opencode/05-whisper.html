05 ／ whisper — 不可視だが実体を持つ

Anomaly Entity / Invisible / 実体あり / 移動する。 不可解な音響・台詞・ゲーム内選択UIによって認知を揺らす。見えないことは「存在しない」ことを意味しない。

(a) 根拠文書

docs/anomalies/whisper.md（Status: Draft）: 音響・認知へ干渉し、指定対象へ付き従う。分かりやすい怪物表示やジャンプスケアにせず、 「いま表示されたものは何だったのか」を判断させる。 whisper 自体は Invisible だが実体を持ち、移動する。出現時に決まった特定プレイヤーへ付き従う。 対象プレイヤーには不可解な台詞・音響・選択肢UIを発生させ得る。 右上の Signal UI は作用を断定しない最小限の反応。HUD で ANOMALY DETECTED のようには答えない。 実OS・実クライアント・ブラウザを操作・終了・外部誘導するUIにはしない。 選択しない・攻撃しないことで表示を消せられるが、消えたことは撃退でも解決でも報酬でもない。 追従先が指定NPCへ接触すると追従先が移り、これが主要な Anomaly Interaction。 博士には whisper が成立しない（迷いなく自分を信じている）。 専用スキル anxiety は対象内に whisper を発生させる。

docs/anomalies/cognitive-anomalies.md: 認識する行為そのものをアノマリー相互作用にする。Observe を必須条件にするかは未決定。

(b) 描画上の仮説

  1. 本体は描かない。 Invisible なので空間には「何もない」。代わりに 音響の波紋・影の落ちた形・UIの影 のみを置く。影は影のまま（多層にしない）。
  2. 目視的表现はUIと音だけ。選択UI・Signal UI・画面上部の微細な揺らぎの3種で存在を示唆する。いずれもゲーム内UIの範囲に収める。
  3. 追従は線で示す。プレイヤーからわずかにずらした位置に波紋の中心を置く。「物体として存在する」のではなく「ついてくる」ことが分かる範囲だけを描く。
  4. 選択UIは意味を持たない架空文面。実在の作品・実在の警告・実在のUIに似せない。文字は意味を欠いた主語と形容詞だけにする（架空）。
  5. 非選択・非攻撃を「消えない選択」として描く。UIには「閉じる」だけの項目は置かず、意味のない項目だけがある形にし、どのを選んでも次のUIが出て続く、という構造を見せた図にする。答えだと分かる暗示はしない。
  6. 博士には何も起きない図を並べる。Quest文書の例外を視覚で示すため、同じ作用が博士に対して空振りするパネルを1つ置く。
描かなかったもの: 本体の外形、System ID、選択UIの具体文面と頻度、対象選定規則、同時存在数、追従先移送後の見た目と共有範囲。

図1 ／ 不可視空間 — 何も描かれていないのに、痕跡がある

図2 ／ 対処と移送 — 消えたことは答えではない

図3 ／ 博士への例外と anxiety — 不快音も潜在要素の引き出しも描かない
