Anomaly Dungeon ／ 視覚仮説ボード（OpenCode 担当分）

アノマリー5体と登場NPC2名の「2Dイメージ案」を、視覚仮説の探索としてまとめたものです。 仕様確定ではなく、外見未定の対象は確定した姿として描かず、複数のシルエットや現象の痕跡を並べています。 Roblox Studio 上の現行外観は参照していません。根拠はすべて docs/ の Draft 文書です。

このボードの扱い

各ページは (a) 根拠文書、(b) 描画上の仮説、(c) 未確定要素 を分けて記載しています。 具体的な顔・衣装・人体構造・意匠の細部を描き切ったものは、すべて 仮案 として扱ってください。 世界の謎の答え、アノマリーの正体、人物の年齢や経歴は描いていません。

混同しないこと: Player Anomaly（Visible / Invisible Inversion）は本ボードの作図対象外です。 Memory Swapper の「通常プレイヤーには見えない／Inversion 発生中のプレイヤーには見える」は Player Anomaly 側の性質として、 Memory Swapper 自身の外見の確定には使わず、参照関係としてだけ注記しています。
